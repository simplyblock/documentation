# Command Assistant

The Command Assistant turns a short task description into the commands to run, in order. It looks the task up in
this version of the documentation and links every step to the page it comes from.

!!! warning "Check Before Running"
    The answers are generated by AI from the documentation. Commands marked **from the docs** appear verbatim on a
    documentation page; commands marked **adapted** are not a literal copy. Read the linked page before running
    anything on a production system.
